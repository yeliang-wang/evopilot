# Evolution Expert v1.1.0 Unified Host Entry

Status: implementation in progress and independently versioned from Runtime 5.1.0.

Expert 1.1.0 extends one Agent-neutral Core with version explanation, capability inventory, migration, shadow, Cutover-readiness, and rollback guidance. Codex, designated-human WorkBuddy, generic Agent, generic MCP, and independent Host adapters are generated from that Core.

The Expert remains a thin client of supported Runtime contracts. It owns no project, Lifecycle, Harness, recovery, evidence, acceptance, release, credential, database, production, or durable state. Headless Runtime operation does not require this package.

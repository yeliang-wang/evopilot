# Evolution Expert 2.1.0

Evolution Expert 2.1.0 adds one Agent-neutral controlled-Lifecycle-evolution journey over Runtime 6.1 MCP. It guides production-reference discovery, observation review, gap classification, immutable successor and semantic-diff review, comparable Champion/Challenger evidence, safe-policy decisions, exact human authority boundaries, monitoring, rollback, restart/resume, and generic-primitive Target proposals.

Codex, Claude Code, designated-human WorkBuddy, generic Agent, and generic MCP bundles are generated from the same immutable Core. Expert remains stateless and non-authoritative: it never invokes a source Suite, owns Runtime state, infers approval, mutates Harness assets, captures raw credentials, executes source work, accepts a Candidate, or publishes a release.

The authoritative scope, acceptance evidence, and release authorization are recorded in `governance/targets/evopilot-evolution-expert-v2.1.0-controlled-lifecycle-evolution.json`. Expert 2.1.0 is compatible with Runtime 6.1.0 and preserves one Agent-neutral Core across all generated Host adapters.

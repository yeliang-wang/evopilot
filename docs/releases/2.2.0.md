# EvoPilot v2.2.0 Release Notes

EvoPilot v2.2.0 adds Harness Knowledge Factory on top of the existing `HarnessTemplateEvolution` lifecycle. It lets administrators evolve reusable harness definitions from historical projects, project corpora, attachments, production logs, and EvoPilot goal/loop history without turning every harness update into a Core binary upgrade.

## What Changed

- Added `source-project`, `source-corpus`, `production-log`, and `evopilot-history` knowledge sources.
- Added production-log redaction before snapshot persistence.
- Added domain signal extraction across database, gateway, cache, scheduler, CRM, messaging, and observability projects.
- Added source coverage fields for `knowledgeCategory`, `gapClassification`, `redactionApplied`, and `projectActions`.
- Added CLI inputs for historical projects, corpora, production logs, EvoPilot history, Office attachments, and best-effort PDF text extraction.
- Upgraded `database-product-harness` and `api-gateway-harness` public packs to `2.2.0`.

## Control-Plane Boundary

Harness upgrades remain server-governed template-version lifecycle records:

```text
CREATED -> SOURCES_COLLECTED -> ANALYZED -> REVIEW_REQUIRED -> APPROVED -> PUBLISHED -> IMPACT_ANALYZED
```

Publishing a template never silently rewrites active `ProjectHarnessProfile` records. Affected projects receive impact evidence and must generate or upgrade a reviewed profile before using the new template digest in goal planning.

## Compatibility

- Compatible Dashboard: `v2.2.0` for Harness Knowledge Factory creation and projection display.
- Compatible CLI/client/contracts packages: `2.2.0`.
- API contract version: `v1`.
- Node.js: 22 or later.
- Docker Compose: v2 for generated self-host stacks and ECS rollout.

## Install Paths

Install the CLI from the GitHub Release tarball set:

```bash
npm install -g \
  https://github.com/yeliang-wang/evopilot/releases/download/v2.2.0/evopilot-contracts-2.2.0.tgz \
  https://github.com/yeliang-wang/evopilot/releases/download/v2.2.0/evopilot-client-2.2.0.tgz \
  https://github.com/yeliang-wang/evopilot/releases/download/v2.2.0/evopilot-cli-2.2.0.tgz
```

Self-host bootstrap from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot/v2.2.0/install.sh | bash -s -- --dir evopilot-stack
```

## Operator Notes

Daily project onboarding still lets EvoPilot automatically match a published template from project context and the goal loop target. Harness Knowledge Factory is an administrator maintenance flow for reusable template upgrades, not a browser-side shortcut for activating project profiles.

Production logs can be provided as evolution sources, but redaction evidence, source coverage, generated pack, validation, diff, changelog, and project impact must be reviewed before approval and publication.

## Rollback

Rollback to `v2.1.0` or the previous image digest, then verify `/health`, `/ready`, project harness template listing, template evolution list, profile generation, Dashboard compatibility, project usage endpoints, and release decisions.

# EvoPilot Runtime 6.3.1 — Token usage without monetary gates

Status: candidate under validation; public release remains [6.3.0](6.3.0.md).

Native process observation v2 records input, output and cached input token counts independently of monetary telemetry. Missing token telemetry stays unavailable; measured zero remains zero. Aggregation never invents a zero monetary amount. Original v1 receipts remain readable.

Runtime no longer estimates model prices or freezes, schedules or judges releases using monetary budgets. Historical externally supplied cost observations remain readable. Token, time, source, scope, evidence, idempotency and authority checks remain in force.

Project-specific validators, narrative journals and the native Codex executor are independent providers/adapters. This patch does not embed legacy Skill Suites or require an Evolution Expert or Harness version bump. Compatibility must be checked against the published Expert 2.3.0 and Harness 4.8.1.

Candidate acceptance covers exact installed bytes, token preservation, money-gate removal, negative boundaries, independent extension paths and recovery. Codex is the real Host scope. Native credential interaction and a new 90-minute soak remain explicitly omitted, not passed. Completion and publication are recorded only after their actual verification.

See [token usage](../architecture/token-usage.md) for the contract and migration details.

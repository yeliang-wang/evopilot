# EvoPilot 6.1.0

Runtime 6.1.0 adds controlled evolution for independently versioned project Pipelines while preserving the v6 Agent-native control plane and Harness-guided Goal Target Loop. Exact observations and user feedback can become deterministic gap classifications, immutable Lifecycle successors, comparable Champion/Challenger reports, policy-bounded future-run activation, declared health monitoring, and receipt-safe rollback.

DataRig Suite 2.1.11 is used only as an exact read-only production reference. Its 20 capability items and 90 critical plus 8 advisory files are covered by provenance in `datarig-production-delivery@1.0.0`; the installed Suite is not invoked or changed. Future project Pipeline revisions remain independent of Runtime and Expert releases unless they require a new project-neutral public primitive.

The authoritative scope, acceptance evidence, and release authorization are recorded in `governance/targets/evopilot-v6.1.0-controlled-lifecycle-evolution.json`. Runtime 6.1.0 is compatible with Evolution Expert 2.1.0, EvoPilot Harness 4.5.0, and the declared external Agent Runtime protocol used by Codex, Claude Code, WorkBuddy, generic MCP, independent Hosts, and headless operation.

# EvoPilot v1.0.3 Release Notes

Release date: 2026-08-02

## Summary

EvoPilot v1.0.3 is the GA publication-hardening patch for the control plane. It preserves the v1.0.0 product contract, includes the Linux service-validation cleanup hardening from v1.0.2, and aligns CLI functional tests with the documented CI client-surface contract.

## Highlights

- The original v1.0.0 GA capability baseline remains unchanged.
- Shell-started validation services are terminated through their POSIX process group when supported.
- CLI status and goal-run tests now expect `ci` in GitHub Actions and `agent-or-script` in normal local automation.
- CI evidence can validate both the service-cleanup path and the CLI CI-surface path on GitHub Linux runners.

## Known Limits

- Public community adoption, external issue traffic, and ecosystem trust require time after publication.
- `v1.0.0` remains the original GA baseline tag; do not force-move it in deployment mirrors.
- `v1.0.1` and `v1.0.2` remain superseded publication-hardening patches; use `v1.0.3` for the latest GA publication evidence.

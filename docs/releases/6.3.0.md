# EvoPilot Runtime 6.3.0 — Semantic Convergence

Status: unreleased source implementation under the approved successor Target.
No Candidate, installed-package acceptance, real Host acceptance, terminal
series E2E or public Release is established by this document.

The accepted convergence pair is Runtime 6.3.0 and Evolution Expert 2.3.0,
consuming published semantic supply from evopilot-harness 4.8.1. Dashboard is
not a dependency of this delivery. Learning Interoperability remains outside
this scope, in Runtime 6.4.0. There is no separate Runtime 6.2.0 user patch or
Expert 2.2.1 publication in this delivery.

The Runtime scope covers published semantic discovery and compatibility,
project and execution bindings, bounded read-only semantic slices, dual-bound
Goal Loop execution, typed evidence, fail-closed validation and recovery.
Harness remains the producer and publication authority; Runtime consumes
published immutable supply and remains the authority for project execution,
credentials, decisions and audit. Expert is the third-party Agent entry, not
an alternative control plane.

Inherited first-run LLM readiness includes explicit opt-in headless bootstrap,
explicit single-candidate v6.1 migration, scoped governed SecretRefs, live
preflight and an explicit workspace binding. Bootstrap input uses non-TTY stdin;
no process-environment credential fallback is retained. Profile changes and
Secret rotation invalidate stale preflight proof; repair requires fresh
preflight and explicit rebinding. See [first-run guidance](../guides/first-run-llm-readiness.md)
and [CLI commands](../cli/commands.md) for the source contract and refusal cases.

The [versioned Runtime corpus](../../tests/e2e/versions/runtime/6.3.0/case-plan.json)
and [Expert corpus](../../tests/e2e/versions/expert/2.3.0/case-plan.json)
retain all current and inherited definitions. Local synthetic test success does
not change their pending formal acceptance status or transfer historical PASS.
Exact Candidate construction, complete installed and independent Host evidence,
the 90-minute active soak and terminal series E2E remain prerequisites to the
separate release decision. Release promotion must reuse the exact accepted
bytes without rebuilding. See [release management](../operations/release-management.md).

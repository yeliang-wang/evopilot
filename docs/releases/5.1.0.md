# EvoPilot v5.1.0 Suite Capability Convergence

Status: implementation in progress. No Candidate, acceptance, publication, or Release is represented by this document.

Runtime 5.1.0 converges the exact latest EvoPilot Codex Suite 3.2.1 and DataRig Codex Suite 2.1.5 capabilities into project-neutral Runtime contracts and independently versioned declarative resources. It adds a 100% capability disposition, resource registry with semantic diff and rollback, typed Action Providers, durable bounded remediation campaigns, and zero legacy-Suite fallback.

DataRig, EvoPilot, evopilot-harness, and new projects remain ordinary declarations. Every Goal Target Loop still requires a published immutable HarnessBundle produced by `evopilot-harness`; EvoPilot does not gain Harness authoring or publication authority.

The installed Suites remain untouched. A real default switch or retirement is post-release work governed by a separate Cutover Target and separate human authorization.

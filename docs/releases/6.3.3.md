# Runtime 6.3.3

This patch ships the approved Agent Host installation, first-task and troubleshooting documentation in the public Runtime packages. Package README links are checked against the actual npm inventory. The checker refuses prepare hooks before invoking npm, including npm 10, to keep validation read-only.

Runtime identity, installers and Helm declarations move to 6.3.3. Existing readiness, authentication, tenant/workspace, token, execution and Harness-consumer semantics are retained. Evolution Expert 2.3.1 and Harness 4.8.2 are independently accepted patch releases; private project extensions 1.0.1 and Dashboard are unchanged.

## Acceptance and publication

The finite maintenance Target requires fresh exact Candidate installation, Codex stdio readback, applicable regression and individual baseline-impact evidence. A new 90-minute soak, paid model invocation and native credential-input interaction are outside this documentation patch's claims and are not counted as passed. Existing private configuration and daily data are preserved.

Candidate formation does not publish a release. Promotion must reuse the exact accepted artifacts, with separate release authorization and a passing Target release gate. See the [current release ledger](current-release.md) for actual publication status, artifact identities and validation evidence.

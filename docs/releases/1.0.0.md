# EvoPilot v1.0.0 Release Notes

Release date: 2026-08-02

## Summary

EvoPilot v1.0.0 is the public GA baseline for the evidence-driven AI-agent product evolution control plane. It includes project harness governance, goal loop planning, human approval gates, loop execution, evidence ingestion, source closure, CI/CD delivery boundaries, LLM profiles, logging diagnostics, and product-native release decisions.

## Highlights

- Project-scoped `ProjectHarnessProfile` generation, review, activation, diff, and policy binding.
- Public `HarnessTemplate` knowledge packs and administrator template evolution lifecycle.
- Alpha/Beta/RC/GA goal loop decomposition with owner approval before execution.
- CLI-first AI Agent operation through JSON output, `nextAction`, stop rules, and request IDs.
- Production deployment assets for API server, loop worker, code-upgrader, and Postgres.
- Standalone Dashboard compatibility through the EvoPilot HTTP API.

## Upgrade Notes

- Read `docs/operations/self-hosting.md` before upgrading a self-hosted deployment.
- Back up Postgres business records and `EVOPILOT_DATA_ROOT`.
- Rebuild EvoPilot services before rebuilding Dashboard.
- Do not move the existing `v1.0.0` tag if it already exists in a deployment mirror.

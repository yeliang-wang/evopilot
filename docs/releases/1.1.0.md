# EvoPilot v1.1.0 Release Notes

EvoPilot v1.1.0 is a GA code-structure evolution release. It keeps the v1.0.10 public product and distribution surface, then moves the current HTTP control-plane runtime behind an explicit runtime boundary while preserving the existing package entrypoints.

## What Changed

- Moved the HTTP control-plane runtime from `packages/server/src/server.ts` into `packages/server/src/runtime/control-plane-runtime.ts`.
- Kept `packages/server/src/server.ts` as a thin compatibility adapter that re-exports the runtime boundary and preserves direct start.
- Extracted shared HTTP error/query helpers into `packages/server/src/http/errors.ts`.
- Extracted static Dashboard asset serving into `packages/server/src/http/static-assets.ts`.
- Extracted file-backed storage primitives into `packages/server/src/storage/json-files.ts`.
- Updated shared package-boundary metadata so runtime logs describe `HTTP control-plane runtime` and `thin compatibility adapter`.
- Expanded `npm run verify:architecture` so the new runtime, HTTP helper, and storage boundaries cannot regress silently.

## Compatibility

- Compatible Dashboard: `v1.0.8` or later.
- Compatible CLI/client/contracts packages: `1.1.0`.
- Node.js: 22 or later.
- Docker Compose: v2 for generated self-host stacks.
- Kubernetes: Helm chart path `charts/evopilot`.

## Install Paths

Self-host bootstrap from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.1.0/install.sh | bash -s -- --dir evopilot-stack
```

Windows PowerShell bootstrap:

```powershell
iwr https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.1.0/install.ps1 -OutFile install.ps1
.\install.ps1 -Dir evopilot-stack
```

Generate with npm directly:

```bash
npx create-evopilot@1.1.0 self-host --dir evopilot-stack --init-env
```

Install the CLI after npm publication:

```bash
npm install -g @evopilot/cli@1.1.0
```

Install the Helm chart from source or the release chart archive:

```bash
helm install evopilot ./charts/evopilot --namespace evopilot --create-namespace
```

## Operator Notes

This release changes source organization, package versions, release metadata, and architecture verification. It does not intentionally change API behavior, CLI stop rules, RBAC, tenant/workspace scope, source-closure gates, release policy, or production authentication requirements.

`packages/server/src/server.ts` is now a compatibility adapter. The current large transitional module is `packages/server/src/runtime/control-plane-runtime.ts`; the next structural target is extracting `FileStore` and route/application use cases behind smaller application and infrastructure modules.

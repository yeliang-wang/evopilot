# EvoPilot v1.1.1 Release Notes

EvoPilot v1.1.1 is a GA code-structure evolution release. It keeps the v1.1.0 control-plane runtime boundary and further reduces the transitional runtime module by extracting runtime auth/config helpers and loop executor adapters into focused modules.

## What Changed

- Extracted runtime mode resolution, production configuration checks, env parsing, user/session token normalization, authorization, RBAC helper, and audit record construction into `packages/server/src/runtime/runtime-auth.ts`.
- Extracted loop executor adapter registration, policy-aware adapter behavior, LLM executor prompt construction, executor boundary labeling, step output, and evidence assembly into `packages/server/src/runtime/executor-adapters.ts`.
- Kept `packages/server/src/runtime/control-plane-runtime.ts` as the transitional HTTP control-plane composition root while reducing its direct ownership.
- Updated shared package-boundary metadata so runtime logs describe `runtime auth/config helpers` and `executor adapters`.
- Tightened `npm run verify:architecture` so the control-plane runtime cannot grow beyond `21600` lines without another boundary extraction, and the new runtime modules have focused line-count guards.

## Compatibility

- Compatible Dashboard: `v1.0.8` or later.
- Compatible CLI/client/contracts packages: `1.1.1`.
- Node.js: 22 or later.
- Docker Compose: v2 for generated self-host stacks.
- Kubernetes: Helm chart path `charts/evopilot`.

## Install Paths

Self-host bootstrap from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.1.1/install.sh | bash -s -- --dir evopilot-stack
```

Windows PowerShell bootstrap:

```powershell
iwr https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.1.1/install.ps1 -OutFile install.ps1
.\install.ps1 -Dir evopilot-stack
```

Generate with npm directly:

```bash
npx create-evopilot@1.1.1 self-host --dir evopilot-stack --init-env
```

Install the CLI after npm publication:

```bash
npm install -g @evopilot/cli@1.1.1
```

Install the Helm chart from source or the release chart archive:

```bash
helm install evopilot ./charts/evopilot --namespace evopilot --create-namespace
```

## Operator Notes

This release changes source organization, package versions, release metadata, architecture docs, and architecture verification. It does not intentionally change API behavior, CLI stop rules, RBAC, tenant/workspace scope, source-closure gates, release policy, or production authentication requirements.

`packages/server/src/runtime/control-plane-runtime.ts` remains a transitional composition root. The next structural target is extracting remaining route/application handlers and then moving `FileStore` behind smaller application and infrastructure modules.

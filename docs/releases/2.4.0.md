# EvoPilot v2.4.0 Release Notes

EvoPilot v2.4.0 adds a one-command Harness evolution workflow on top of the existing HarnessTemplate lifecycle. Ordinary administrators can point EvoPilot at a source project and goal, then let the control plane scan, auto-match, create or resume an evolution run, and advance it to a reviewable draft.

## What Changed

- Added `POST /api/v1/harness/template-evolutions/evolve`.
- Added `evopilot harness evolve --source-project <path> --goal <text> --json`.
- Added `evopilot-harness-evolve-result/v1` and CLI wrapper output `evopilot-harness-evolve-command-result/v1`.
- Preserved atomic lifecycle commands for match, create, advance, approve, publish, and impact.
- Kept default one-command behavior stopped at `REVIEW_REQUIRED`; approval and publish remain explicit administrator actions.
- Added Dashboard compatibility for the same server-side one-command workflow.

## Control-Plane Boundary

The normal path is:

```text
harness evolve -> REVIEW_REQUIRED -> administrator review -> approve -> publish -> impact
```

`harness evolve` does not make the browser or CLI the system of record. The server still owns RBAC, tenant/workspace scope, source snapshots, audit, validation, lifecycle state, and next action. Low-confidence auto-match, blocked source extraction, draft validation blockers, or lifecycle gates stop the workflow and return `nextAction`.

## Compatibility

- Compatible Dashboard: `v2.4.0`.
- Compatible CLI/client/contracts packages: `2.4.0`.
- API contract version: `v1`.
- Node.js: 22 or later.
- Docker Compose: v2 for generated self-host stacks and ECS rollout.

## Install Paths

Install the CLI from the GitHub Release tarball set:

```bash
npm install -g \
  https://github.com/yeliang-wang/evopilot/releases/download/v2.4.0/evopilot-contracts-2.4.0.tgz \
  https://github.com/yeliang-wang/evopilot/releases/download/v2.4.0/evopilot-client-2.4.0.tgz \
  https://github.com/yeliang-wang/evopilot/releases/download/v2.4.0/evopilot-cli-2.4.0.tgz
```

Self-host bootstrap from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot/v2.4.0/install.sh | bash -s -- --dir evopilot-stack
```

## Operator Notes

Use `harness evolve` for the normal source-project experience. Use `harness template match` when you only need a read-only match preview, and use atomic `harness template evolution ...` commands for CI, failure recovery, administrator review, explicit approval, publishing, and impact analysis.

Public npm registry packages are a separate publication layer. This release remains installable through GitHub Release tarballs until npm publication is separately executed and verified.

# EvoPilot v1.0.10 Release Notes

EvoPilot v1.0.10 is a GA code-structure and module-boundary cleanup patch. It keeps the v1.0.9 distribution surface, then makes the server package entrypoint thin, moves reusable HTTP concerns out of the entrypoint, and adds architecture verification so the same hotspots do not regress.

## What Changed

- Replaced the 25k-line server package entrypoint with a thin `index.ts` that exports server APIs and delegates direct startup to `startServerFromEnvironment`.
- Added `packages/server/src/server.ts` as the transitional HTTP composition root while deeper route, store, and application use-case extraction continues.
- Added `packages/server/src/model.ts` for server-side API, store, goal, loop, release, and Dashboard projection contracts.
- Added HTTP helper modules for platform readiness/version bodies, structured request logging, response writers, server logging, route dispatch, and focused platform/auth/settings/read-model routes.
- Moved built-in enterprise `HarnessTemplate` defaults into `packages/server/src/domains/harness-template/defaults.ts`.
- Expanded `npm run verify:architecture` with explicit file-presence and line-budget checks for entrypoints, route modules, model contracts, and HTTP infrastructure helpers.

## Compatibility

- Compatible Dashboard: `v1.0.8` or later.
- Compatible CLI/client/contracts packages: `1.0.10`.
- Node.js: 22 or later.
- Docker Compose: v2 for generated self-host stacks.
- Kubernetes: Helm chart path `charts/evopilot`.

## Install Paths

Self-host bootstrap from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.0.10/install.sh | bash -s -- --dir evopilot-stack
```

Windows PowerShell bootstrap:

```powershell
iwr https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.0.10/install.ps1 -OutFile install.ps1
.\install.ps1 -Dir evopilot-stack
```

Generate with npm directly:

```bash
npx create-evopilot@1.0.10 self-host --dir evopilot-stack --init-env
```

Install the CLI after npm publication:

```bash
npm install -g @evopilot/cli@1.0.10
```

Install the Helm chart from source or the release chart archive:

```bash
helm install evopilot ./charts/evopilot --namespace evopilot --create-namespace
```

## Operator Notes

This release changes code organization and package metadata. It does not intentionally change API behavior, CLI stop rules, RBAC, tenant/workspace scope, source-closure gates, release policy, or production authentication requirements.

`packages/server/src/server.ts` remains a transitional composition root. The next structural target is extracting the remaining route/application handlers and `FileStore` behind smaller application and infrastructure modules.

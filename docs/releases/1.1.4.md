# EvoPilot v1.1.4 Release Notes

EvoPilot v1.1.4 is a GA distribution-closure patch release. It keeps the v1.1.3 code-structure and npm publication verification work, then makes the supported public installer and CLI paths resolve package specs from GitHub Release tarballs when public npm registry packages have not been published yet.

## What Changed

- Updated `install.sh` and `install.ps1` to support manifest-provided `packageSpec` / `tarballUrl` values and the `EVOPILOT_INSTALL_PACKAGE_SPEC` override.
- Updated `installers/manifest.json` so `create-evopilot` defaults to a GitHub Release tarball package spec, `@evopilot/cli` records its GitHub Release dependency tarball set, and both package entries record `registryStatus: not_published`.
- Corrected README, distribution, self-hosting, CLI, package, release-management, open-source readiness, and maturity documentation so public npm registry installation is treated as a separate post-publish layer.
- Updated package versions, shared version fallbacks, installer defaults, OpenAPI metadata, and release validation pointers to `1.1.4`.
- Updated `npm run verify:distribution` so local dry-run installer verification uses the repository manifest before the release tag exists.

## Compatibility

- Compatible Dashboard: `v1.0.8` or later.
- Compatible CLI/client/contracts packages: `1.1.4`.
- Node.js: 22 or later.
- Docker Compose: v2 for generated self-host stacks and ECS immutable rollout.
- Kubernetes: Helm chart path `charts/evopilot`.

## Install Paths

Install the CLI from the GitHub Release tarball set:

```bash
npm install -g \
  https://github.com/yeliang-wang/evopilot/releases/download/v1.1.4/evopilot-contracts-1.1.4.tgz \
  https://github.com/yeliang-wang/evopilot/releases/download/v1.1.4/evopilot-client-1.1.4.tgz \
  https://github.com/yeliang-wang/evopilot/releases/download/v1.1.4/evopilot-cli-1.1.4.tgz
```

Self-host bootstrap from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.1.4/install.sh | bash -s -- --dir evopilot-stack
```

Windows PowerShell bootstrap:

```powershell
iwr https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.1.4/install.ps1 -OutFile install.ps1
.\install.ps1 -Dir evopilot-stack
```

Install the Helm chart from source or the release chart archive:

```bash
helm install evopilot ./charts/evopilot --namespace evopilot --create-namespace
```

## Public npm Boundary

Public npm registry packages are not published in this release layer. The repository includes `.github/workflows/npm-packages.yml` and `npm run verify:npm-registry` for that separate action.

After npm publication, verify the public registry path:

```bash
npm run verify:npm-registry -- --version 1.1.4
```

Only after that command passes should operators use:

```bash
npm install -g @evopilot/cli@1.1.4
npx create-evopilot@1.1.4 self-host --dir evopilot-stack --init-env
```

## Immutable ECS Rollout

Resolve and deploy one release digest:

```bash
npm run ecs:immutable-rollout -- \
  --version 1.1.4 \
  --host root@8.153.72.80 \
  --apply \
  --json
```

Run a rollback and forward drill:

```bash
npm run ecs:immutable-rollout -- \
  --rollback-version 1.1.2 \
  --forward-version 1.1.4 \
  --host root@8.153.72.80 \
  --apply \
  --json
```

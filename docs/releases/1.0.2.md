# EvoPilot v1.0.2 Release Notes

Release date: 2026-08-02

## Summary

EvoPilot v1.0.2 is the GA publication-hardening patch for the control plane. It preserves the v1.0.0 product contract and hardens Linux CI cleanup for shell-started validation services in the built-in code-upgrader runtime tests.

## Highlights

- The original v1.0.0 GA capability baseline remains unchanged.
- Service validation now starts shell commands in a POSIX process group when supported.
- Cleanup terminates the whole validation process tree, not only the shell wrapper.
- CI evidence can complete cleanly on GitHub Linux runners after service smoke and functional checks.

## Known Limits

- Public community adoption, external issue traffic, and ecosystem trust require time after publication.
- `v1.0.0` remains the original GA baseline tag; do not force-move it in deployment mirrors.
- `v1.0.1`, `v1.0.2`, and `v1.0.3` remain superseded GA publication patches; use `v1.0.4` for immutable release artifact evidence.

# EvoPilot v1.0.8 Release Notes

EvoPilot v1.0.8 is a GA distribution-expansion patch. It keeps the v1.0.0 product contract and v1.0.7 release-readiness matrix, then adds installable public entry points for CLI users, self-hosted operators, and Kubernetes teams.

## What Changed

- Added npm package boundaries for `@evopilot/contracts`, `@evopilot/client`, `@evopilot/cli`, and `create-evopilot`.
- Added `create-evopilot self-host --init-env` to generate a Docker Compose stack plus random local auth and database secrets.
- Added guarded `create-evopilot self-host --start`; it refuses to start when unresolved production placeholders remain in `.env`.
- Added tagged `install.sh` so operators can bootstrap from a release tag with `curl -fsSL ... | bash`.
- Added Helm chart packaging at `charts/evopilot` with a Secret-backed production values example.
- Added distribution verification for npm tarballs, empty-project binary install, initialized stack output, Helm chart structure, and production values.
- Added npm package publishing workflow with release-tag validation and npm provenance.

## Compatibility

- Compatible Dashboard: `v1.0.6` or later.
- Compatible CLI/client/contracts packages: `1.0.8`.
- Node.js: 22 or later.
- Docker Compose: v2 for generated self-host stacks.
- Kubernetes: Helm chart path `charts/evopilot`.

## Install Paths

Self-host bootstrap from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot/v1.0.8/install.sh | bash -s -- --dir evopilot-stack
```

Generate with npm directly:

```bash
npx create-evopilot@1.0.8 self-host --dir evopilot-stack --init-env
```

Install the CLI after npm publication:

```bash
npm install -g @evopilot/cli@1.0.8
```

Install the Helm chart from source or the release chart archive:

```bash
helm install evopilot ./charts/evopilot --namespace evopilot --create-namespace
```

## Operator Notes

`--init-env` writes a local `.env` with random auth and database secrets. It still requires a real LLM endpoint, model, and API key before production readiness can pass.

`--start` runs Docker Compose only when unresolved placeholders have been removed. Use it after setting `EVOPILOT_LLM_BASE_URL`, `EVOPILOT_LLM_MODEL_NAME`, and `EVOPILOT_LLM_API_KEY`, or after editing `.env`.

Desktop installer and hosted Cloud trial remain outside the published EvoPilot surface for this release.

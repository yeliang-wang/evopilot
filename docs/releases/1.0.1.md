# EvoPilot v1.0.1 Release Notes

Release date: 2026-08-02

## Summary

EvoPilot v1.0.1 is a GA publication-hardening patch for the control plane. It preserves the v1.0.0 product contract and fixes the Linux CI service-validation cleanup path used by the built-in code-upgrader runtime tests.

## Highlights

- The original v1.0.0 GA capability baseline remains unchanged.
- Built-in service validation now waits for spawned validation services to close after sending a termination signal.
- CI evidence can complete cleanly on GitHub Linux runners instead of leaving a service process handle behind.

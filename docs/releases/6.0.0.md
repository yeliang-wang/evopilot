# EvoPilot 6.0.0

EvoPilot 6.0.0 establishes the Agent-native Lifecycle control plane. It keeps
project-specific Pipelines declarative and outside the Runtime kernel, while an
external Agent Runtime executes source work under an exact qualified binding.

Release scope:

- tenant/workspace governed Lifecycle Registry with immutable revision lifecycle;
- Expert-over-MCP ordinary-human operation;
- exact qualified external Agent Runtime execution boundary;
- mandatory published immutable HarnessBundle plus Lifecycle binding for Goal Target Loops;
- declaration-only third-party project Pipeline management with no project-name branch;
- frozen legacy Suites as reference fixtures only;
- exact Runtime 6 / Expert 2 completion contract and cross acceptance.

Runtime 6.0.0 is paired with Evolution Expert 2.0.0 and remains compatible with
published `@evopilot/harness` 4.5.0 assets. The exact accepted Candidate bytes are
promoted without rebuilding to the GitHub Release, six npm packages, and the
`ghcr.io/yeliang-wang/evopilot` container tags.

The governed Target and its 176-item Runtime acceptance projection remain the
authoritative release record:
`governance/targets/evopilot-v6.0.0-agent-native-lifecycle-control-plane.json`.

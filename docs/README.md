The parent is an index for independently versioned components. Use the documentation and release of the component you operate.

| Task | Owner and entry |
|---|---|
| Configure Project Lifecycle YAML, inspect execution gates or monitor instances | [Runtime documentation](https://github.com/yeliang-wang/evopilot-runtime/blob/main/docs/README.md) |
| Build, review or publish semantic assets | [Ontology documentation](https://github.com/yeliang-wang/evopilot-ontology/blob/main/docs/README.md) |
| Build, review or publish quality rules and Harness assets | [Harness documentation](https://github.com/yeliang-wang/evopilot-harness/blob/main/docs/README.md) |
| Operate an existing combined v0.8.3 installation | [Versioned installation guide](https://github.com/yeliang-wang/evopilot/blob/v0.8.3/docs/installation.md) and [historical documentation](https://github.com/yeliang-wang/evopilot/blob/v0.8.3/docs/README.md) |

For current downloads and compatibility, follow the owning component's Release and migration instructions. Historical parent files remain reference material; they do not activate old services or authorize a migration.

The parent still retains historical combined-service, Expert/plugin, build and shared-contract sources. This navigation transition does not claim that those files have all been removed or that Ontology/Harness have already completed their future separation.

# EvoPilot Codex plugin first release

User-approved scoped first release for existing configured stable product installations. Plugin0.1.0; Runtime/CLI/MCP6.3.3 and Expert2.3.1 remain unchanged. macOS arm64 and preinstalled Node24.14.

Explicit selection plus submitted instruction -> plugin start -> identity-verified registered service start/reuse -> owner readiness -> supported official Runtime MCP operations. Passive discovery does not start the service; conversation end does not stop it. Existing authorization, configuration and data are retained.

- CORE-ACTIVATION: Explicit selected plugin and submitted instruction activates only that bridge; passive list/init and ordinary-chat control start no Runtime.
- CORE-START: Configured registered stopped launchd service starts once on explicit start; concurrent start and later chats reuse actual known PID; no automatic stop or unknown-process takeover.
- CORE-IDENTITY: Registration pins service/plist/program/package; authenticated Runtime scope/version plus actual listening PID match; mismatch, missing service, timeout and changed source refuse.
- CORE-FUNCTION: READY connection relays supported official Runtime6.3.3 MCP functions and preserves owner scope, authorization, results, errors and request IDs; no plugin permission escalation.
- CORE-CONFIG: Existing service private API configuration is used locally; no raw credentials in chat/artifact/log/argv; no copying or modifying existing data, credentials or model profile.
- CORE-FAILURE: Missing/invalid configuration and readiness accurately refuse affected work; unknown mutation outcomes never auto-retry; no global/private fallback.
- PACKAGE: Plugin0.1.0 has complete pinned public dependencies, supported macOS arm64/Node24.14 prerequisites, finite install/doctor and declared exclusions; no private helpers.
- DESKTOP: Exact accepted bytes pass current Codex Desktop selected start/status/real supported call, continued/new-chat reuse, ordinary-chat and failure controls.
- REGRESSION: Focused positive/negative tests and actual stable-product compatibility pass; published dependency bytes are not modified and previous work/uncertain records remain retained.
- RELEASE: Freeze exact accepted plugin package, source and public dependency identities; candidate acceptance and owner release gates pass before publication. Public readback and reinstallation remain mandatory separate postpublication checks.

Deferred: Full Runtime6.5/Expert2.4/Harness4.8.3 upgrades and original R3 100% claim; Public executor/collector first delivery or private project-extensions redistribution; Fresh suite install, automatic stop/upgrade/data adoption/rollback or historical data copying; Global Host enforcement or preventing native tools; no private Codex IPC; Unrelated source, daily data, credentials, global model settings or retired Suites.

This release does not satisfy original R3 full-series completion. Nonblocking issues are recorded for follow-up; core behavior, privacy, actual owner identity, exact-byte/public availability and current Desktop compatibility block release. Release authorization is evaluated before publication; public readback/reinstall is checked afterward and cannot be claimed in advance.

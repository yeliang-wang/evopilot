# Retained usability assessments

The user authorized continuation of the accepted v0.8 plan through conditional release. The [delivery Target](../../governance/asset-usability-v08-delivery.json) retains every requirement and acceptance ID, fixed variants and resource bounds. This decision extends the read-only T1 foundation in 0006; it does not change the three product owners or native package standards.

Harness owns immutable reviewed question/behavior inventories, specification records, independent semantic reviews and versioned assessments. Runtime owns reconstruction attempts and their protected execution receipts. Ontology continues to own published normative assets. The parent only composes public APIs. Preflight remains read-only and never awards a level.

Freeze an inventory and its exact normative asset/file bindings using actual review evidence. Store specifications by digest. Semantic reviews fix every question and applicable behavior facet; missing, duplicate, foreign, synthetic or unresolved outcomes cannot verify a level. A human review reference binds the exact independent semantic report; a blanket implementation/release authorization is not such a reference. Evaluation rereads published normative bytes and current pins through trusted host providers. No request-supplied PASS or freshness assertion replaces these reads.

Assessments retain the target and highest supported level separately. L2 requires L1. L3 additionally requires protected, independent Runtime reconstruction and Harness oracle evidence; while those adapters are absent it remains unsupported. Listing mixed slices never averages grades or expands scope. A changed scope is a new inventory. Reads of stale results expose the historical result and current stale disposition without rewriting history.

An L3 assessment explicitly selects two to four immutable oracle evaluation IDs at creation. All selected evaluations must pass for the exact inventory/specification/oracle binding. Protected observations must still match the evaluated digests and carry Runtime-sealed execution identity. Two evaluations of one attempt, reused clean workspaces, repeated claim/receipt identities, mixed plans, changed executors and legacy observations without execution identity cannot qualify. All L1/L2 semantic criteria remain prerequisites. The recorded evidence is the exact oracle-result digest list, not a caller-supplied PASS. Current readback rechecks those same proofs and semantic decision without executing software; unavailable evidence cannot preserve a current L3 claim.

Before asynchronous evaluation, retain an immutable claim. Exact retries inspect that claim; they do not dispatch another evaluation. Interrupted evaluation remains in progress until explicit reconciliation records incomplete evidence. Provider reads use finite deadlines and abort signals. After evaluation, recheck source, assets, oracle, environment and dependency pins before recording a terminal result.

Use the existing owner-local extension store and audit, with new record kinds. The first assessment write raises Harness's state marker to 7; old writers reject it. Snapshot/restore retains all versions and claims. Reverting requires a stopped complete pre-upgrade backup. Historical assets and receipts gain no retroactive grades. No new external network endpoint or mutation authority is introduced by this stage.

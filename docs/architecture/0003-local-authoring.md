# Native local authoring and assembly

The v0.6.0 Preview candidate parent owns canonical compatibility bytes, strict TypeScript composition, connection, Expert and plugin code, integration tests, documentation and assembly tooling. Child Runtime, Harness and Ontology repositories own independent source, checks, declarations and exact dependency locks. See the [language policy](../language-policy.md) for generated and test-driver exceptions.

Qualify the explicit project and files before a Runtime-owned edit request. A parent scope does not authorize child edits. An isolated editor may have unpopulated gitlinks; missing children must be reported, never silently restored or treated as passing checks. Keep current daily state, credentials, pending requests and retained receipts in place.

The integration operator promotes reviewed edits into the populated parent, builds each locked child before parent public imports, binds the local packages without modifying locks, then emits parent JavaScript and runs check/test and artifact verification. Component locks require clean exact child HEADs matching parent index gitlinks. Compiled entry points and source maps are described in [development](../development.md).

Parent composition supplies deterministic validation/evaluation integration to Runtime; standalone Runtime still requires its explicit callbacks. Product ownership, approval, publication and reconciliation remain separate. An uncertain response never authorizes redispatch.

Preserve immutable v0.1.0, M0 and M1 history. The v0.1.1 repair projection is informational. Delivery proceeds from source checks to exact candidate acceptance and installed readback. The current v0.6 Target authorizes implementation and local installation; earlier conditional release decisions do not authorize v0.6 GitHub publication. Follow the applicable exact-candidate decision before publication and tag/download verification. See [release delivery](../github-release.md) and [testing](../testing.md). No local edit or build establishes acceptance.

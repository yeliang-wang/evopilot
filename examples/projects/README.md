# Declarative project definitions

These files are reference instances of the same `evopilot-evolution-project-definition/v1` aggregate. DataRig, EvoPilot, and evopilot-harness do not have privileged branches in Runtime code. Copy `new-project.yaml`, answer the schema fields through Evolution Expert over MCP, then register a new immutable version. Direct YAML editing is an administrator or machine path, not the ordinary-human product entry.

A Project Definition declares facts, references, delivery rules, Hosts, and execution runtimes. It does not embed credentials, Harness assets, executable scripts, approval, or release authority.

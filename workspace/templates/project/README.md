# My EvoPilot Workspace

This is your private local project, created by EvoPilot 0.2.0. It contains editable assets and project records; it is separate from product source and protected service databases.

1. Select the EvoPilot plugin in Codex and ask it to inspect this Workspace.
2. Start with the [forward example](examples/forward/README.md) or [reverse example](examples/reverse/README.md).
3. Ask Expert to connect your own project. Reading an existing source project does not authorize edits to it.
4. Review ontology and Harness drafts before delivery. Runtime uses exact delivered versions, not saved drafts.
5. Keep Goal, Target and Loop evidence under `private/`; public assets are reusable but never uploaded automatically.

Git and GitHub are optional. Do not commit credentials, service databases, raw audit logs or machine connection configuration. Git history is not a complete service backup. See [storage](docs/storage.md).
